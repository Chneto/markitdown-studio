Degravação de Vídeo & Áudio

Equipado com Faster-Whisper Large-v3, o modelo de maior precisão para Português (pt-BR), gerando timestamps sequenciais e métricas de fala por minuto.

🔍

OCR Neural Offline

Motor RapidOCR ONNX integrado para leitura de imagens e PDFs digitalizados sem depender de APIs externas, com pré-aquecimento instantâneo.

⚡

Zero Sobrecarga de RAM

Arquitetura em streaming que processa arquivos de vídeo gigantescos (1 GB a 4 GB) diretamente do disco, evitando picos de consumo de memória.

🤖

Integração Google Gemini

Suporte opcional a modelos multimodais como Gemini 2.0 Flash para enriquecimento e sumarização avançada via chave de API.

100% Local & Privado

Atalhos rápidos de teclado (Ctrl+O, Ctrl+Enter), editor ao vivo, temas dark/light e abertura direta no Windows Explorer.

Instalação e Execução Rápida

Configure e execute o MarkItDown Studio em menos de 2 minutos.

# 1. Clonar o repositório
git clone https://github.com/SEU_USUARIO/markitdown-studio.git
cd markitdown-studio

# 2. Instalar dependências
pip install -r requirements.txt

# 3. Iniciar a aplicação Desktop
python -m studio.app
